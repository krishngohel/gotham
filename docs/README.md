# Docs index

What each document is for. The player-facing overview, controls and how to run the checks are in
the top-level [README](../README.md); licences in [CREDITS](../CREDITS.md).

## Contract and process

- [design/long-night-2.md](design/long-night-2.md): the Long Night 2 overhaul contract: intent, hard rules, shared architecture (players, regions, quality tiers, co-op), workstreams.
- [baseline/README.md](baseline/README.md): what "not broken" meant before the overhaul (test counts, playthrough, perf, animation audit), with the raw logs beside it.

- [design/polish-list.md](design/polish-list.md): open polish items collected at integration; tick off with the fixing commit.
